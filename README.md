# دليل تشغيل ونشر موقع "حقيقة أبي عبيدة النقادي"

تم إعداد هذا الموقع الإلكتروني خصيصاً ليعمل على نطاق GitHub المجاني الخاص بمنظمتكم:
🌐 **`https://abu-obaidah-ennaqqadi.github.io/`**

وهو نطاق مثالي جداً لمحركات البحث (SEO) لاشتماله المباشر على الاسمين المستهدفين: `abu-obaidah` و `ennaqqadi`.

---

## خطوات التفعيل والنشر خلال 60 ثانية:

### 1. إنشاء المستودع في المنظمة:
1. ادخل إلى رابط منظمتك على GitHub:  
   👉 **[https://github.com/abu-obaidah-ennaqqadi](https://github.com/abu-obaidah-ennaqqadi)**
2. اضغط على الزر الأخضر **New repository**.
3. في خانة **Repository name**، اكتب بدقة:
   👉 **`abu-obaidah-ennaqqadi.github.io`**
   *(ملاحظة: كتابة هذا الاسم بالضبط ضرورية لكي يعمل الموقع كنطاق رئيسي).*
4. اختر أن يكون المستودع **Public**.
5. ضع علامة صح على **Add a README file**.
6. اضغط على الزر الأخضر بالأسفل: **Create repository**.

---

### 2. رفع ملفات الموقع:
1. في صفحة المستودع الجديد، اضغط على زر **Add file** (في الأعلى إلى اليمين) ثم اختر **Upload files**.
2. اسحب وأفلت الملفات الـ 4 التالية:
   - **`index.html`**
   - **`styles.css`**
   - **`sitemap.xml`**
   - **`robots.txt`**
3. اضغط بالأسفل على زر **Commit changes**.

---

### 3. التأكد من تفعيل GitHub Pages (تلقائي):
- عادةً يقوم GitHub بتفعيل النشر تلقائياً للمستودعات التي تنتهي بـ `.github.io`.
- للتأكد: اذهب إلى **Settings** (في أعلى المستودع) -> ثم اضغط على **Pages** من القائمة الجانبية.
- تأكد أن **Build and deployment / Source** مضبوط على **Deploy from a branch** وأن الـ Branch هو `main`.

---

خلال 1-2 دقيقة، سيكون موقعك متاحاً ويعمل على الإنترنت عالمياً عبر:  
🔗 **`https://abu-obaidah-ennaqqadi.github.io/`**
